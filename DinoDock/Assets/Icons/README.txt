App logos
=========

Each launcher card shows {Id}.png from this folder (google.png, hulu.png, youtube.png).
Replace a file to change that card's logo; square, 256x256, transparent background works best.
Delete a file to fall back to the built-in glyph defined in Models/AppCatalog.cs.

Sources: Google/YouTube from the Iconify "logos" set (CC0), Hulu from CoreUI brand icons (CC0).
